## Ответ на вопрос: 
Всего 14 уникальных календарей, 1 января может выпасть на 7 дней недели, а также может быть високосный год, получается 7*2=14.



## Использовались
- **Java 17** 
- **Maven**

## Сборка проекта
Для сборки исполняемого jar-файла необходимо выполнить в корне проекта команду:
```bash
mvn clean package
```
## Запуск проекта

Запустить файл можно командой:

```bash
java -jar target/calendar-1.0-SNAPSHOT.jar
```
